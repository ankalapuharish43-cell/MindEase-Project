🧠 MindEase – AI Mental Health Companion

An AI-powered chatbot designed to support student mental well-being by detecting emotional states using Machine Learning and providing empathetic responses along with relaxation techniques.

📌 Project Overview

Students today face stress, anxiety, academic pressure, and loneliness. Many hesitate to approach professional counselors.

MindEase acts as a first-level AI companion that:

Detects user mood from text input

Classifies emotions as Positive, Negative, or Neutral

Provides supportive and motivational responses

Suggests breathing exercises and self-care tips

Displays calming visual elements

🚀 Features

🧠 Mood Detection using Machine Learning

📊 TF-IDF Text Vectorization

🤖 Logistic Regression Classification

🌿 Relaxation Suggestions for Negative Mood

😊 Motivational Messages for Positive Mood

🎨 Interactive Web UI built with Streamlit

☁️ Deployable on Streamlit Cloud

🛠 Technologies Used

Python

Streamlit

Scikit-learn

TF-IDF Vectorizer

Logistic Regression

Git & GitHub

🏗 System Architecture

User enters text describing their feelings

Text is converted into numerical features using TF-IDF

Logistic Regression model predicts mood category

Based on prediction:

Positive → Encouraging message

Negative → Relaxation tips + calming visuals

Neutral → Light suggestions
